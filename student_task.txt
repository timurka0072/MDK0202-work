------------------------------------------------------------------------
ВХОДНЫЕ ДАННЫЕ (СТРУКТУРА РЕПОЗИТОРИЯ)
------------------------------------------------------------------------
Все исходные файлы находятся в папке src/
- src/gui.ui       — интерфейс приложения для редактирования в Qt Designer
- src/gui.py       — сгенерированный Python-код интерфейса (команда: pyuic5 "./src/gui.ui" -x -o ./src/gui.py)
- src/main.py      — главная логика калькулятора
- requirements.txt — список зависимостей для установки (pip install -r requirements.txt)
- README.md        — описание проекта

Откройте файлы в любом текстовом редакторе. Для просмотра интерфейса можно использовать Qt Designer (или изучить структуру XML в gui.ui). Запускать приложение не обязательно, но рекомендуется для понимания потока данных.

[ЧАСТЬ 3] Проектирование тестовой документации 
1. Выберите одну функцию калькулятора (например: деление, очистка, ввод десятичных дробей).
2. Разработайте 6-8 тест-кейсов, обязательно включив:

   - 1 граничное значение (макс. длина ввода, 0.0, отрицательные числа)
