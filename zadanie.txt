ЧАСТЬ 1. Первичный анализ структуры проекта (45-60 мин) <<<
Клонируйте репозиторий и изучите структуру каталогов:


Составьте дерево файлов проекта

Для каждого .py-файла в папке main/ или корневой директории:
[1] Определите его предполагаемое назначение по имени и импортам
[2] Запишите, какие внешние библиотеки он использует
[3] Отметьте, с какими другими файлами он может взаимодействовать


ЧАСТЬ 2. Анализ потоков данных и зависимостей  <<<
Выберите точку входа в приложение (файл, который запускается первым)
Проследите цепочку вызовов от точки входа:
[ ] Какие модули инициализируются первыми?
[ ] Какие данные передаются между функциями/классами?
[ ] Есть ли циклические зависимости?
Составьте таблицу модулей по шаблону:
+-------------------+------------------+------------------+---------------+
| Файл | Назначение | Зависит от | Типы данных |

ЧАСТЬ 3. Построение диаграмм <<<
На основе анализа создайте ДВЕ диаграммы:

[ДИАГРАММА 1] Компонентная диаграмма 
Отобразите основные модули проекта как компоненты
Покажите зависимости стрелками с подписями:
"инициализирует"
"передает данные"

[ДИАГРАММА 2] Диаграмма потоков данных 
Покажите, как данные перемещаются между модулями
Укажите источники и получатели:
Пример: [Пользователь] -> [InputHandler] -> [WorldGenerator]
